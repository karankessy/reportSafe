# **App Name**: ReportSafe

## Core Features:

- Guided Submission: Intuitive vulnerability submission form with progressive disclosure to guide researchers.
- Status Dashboard: Dashboard displaying the status of submitted reports with clear, color-coded indicators.
- AISeverity Tool: AI-powered severity assessment tool that analyzes report details and suggests severity levels, with a human-in-the-loop override feature.
- Direct Communication: Integrated communication channel for direct interaction between researchers and the security team. Includes ability to upload supporting media.
- WYSIWYG: A simple WYSIWYG editor to let security researchers simply record what they've discovered.

## Style Guidelines:

- Primary color: Moderate blue (#3477eb) to promote trust and reliability.
- Background: Soft gray (#f8f9fa) to create a calm, neutral foundation.
- Accent: Purple (#9060ed), a vivid and attention-grabbing tone shifted from the primary hue, balanced between blue and violet for an elevated look.
- Clean and modern font for headings and body text to ensure readability.
- Use a set of consistent, professional icons to visually represent different report statuses and actions.
- Card-based layout for reports and notifications to maintain consistency and organization.
- Subtle animations and transitions to provide feedback and enhance user experience.
